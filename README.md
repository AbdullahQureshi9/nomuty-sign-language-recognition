# NOMUTY – Hand Sign Recognition Application

## Overview

NOMUTY is a Final Year Project developed to assist deaf and mute individuals by recognizing hand signs and converting them into readable text.

The project uses computer vision and machine learning techniques to process hand gestures and classify signs using image-based recognition.

## Problem Statement

Many deaf and mute individuals use sign language to communicate, but most people do not understand sign language. This creates a communication barrier.

NOMUTY aims to reduce this gap by recognizing hand signs through a camera-based system and converting them into text.

## Key Features

- Hand sign recognition
- Image capturing
- Image preprocessing
- Region extraction
- Feature extraction
- Feature matching
- Pattern recognition
- Sign-to-text conversion
